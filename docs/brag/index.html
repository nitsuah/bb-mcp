bb-mcp

MCP server for Blackboard Learn. 40 tools, 5 personas, email scrubbing on successful tool responses.

Student Tools (9)

Upcoming assignments, grades, announcements, course content, submission status — all in one call.

Instructor Tools (7)

Roster, grade distribution, at-risk students, discussion summaries, AI-assisted announcements.

Grade Write-Back (6)

Create assignments, grade columns, update/delete/exempt grades — FERPA-gated, course-entitled.

Admin Tools (7)

User directory, enrollments, audit logs — all with local access-audit trail.

Parent Tools (5)

Guardian-scoped read-only: children's courses, grades, upcoming work, announcements.

Security First

MCP_API_KEY gate (when configured), per-role rate limits, FERPA gate, email scrubbing on successful tool responses, audit logging.

Get Started

git clone https://github.com/nitsuah/bb-mcp && cd bb-mcp && npm ci && npm run build && node dist/index.js --stdio
